# Security Policy

## Supported version

Security fixes currently target the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening a public issue. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not include real class schedules, API keys, personal identifiers, or notification payloads in a report. Replace them with minimal synthetic data.

## Local data

KeXu stores schedules and settings locally. Exported backup files and locally saved DeepSeek API keys may contain sensitive information; users should protect device access and avoid sharing unredacted backups.
